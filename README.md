# 产品知识工作台 · 访问入口

本仓库只托管**一个静态访问入口页**（GitHub Pages），给同事一条**永久不变**的网址。

- 打开后点「进入工作台」即可跳转到工作台登录页
- 页面本身**不含任何产品资料**；资料需登录后按账号授权下发
- 工作台运行在管理员办公电脑上，关机 / 休眠期间无法访问

## 访问地址

启用 GitHub Pages 后：

    https://yunzi13866684081.github.io/product-kbOS/

## 它是怎么保持"地址永久有效"的

访问入口页是静态壳，真正的地址放在同目录的 `current.json`。
管理员电脑上的看护进程会在地址变化时自动重写 `current.json` 并推送，
因此本页链接**始终指向当前可用地址**，同事收藏后无需更换。

## 维护

- 地址变化：在管理员电脑上运行 `更新入口页并推送.vbs`（或等看护进程自动同步）
- 想关闭入口：把本仓库设为 Private 或在 GitHub 后台关闭 Pages
